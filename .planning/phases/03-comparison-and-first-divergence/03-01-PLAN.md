# Phase 3 Plan 01: Comparison and first divergence

Requirements: CMP-01..CMP-04. Plan authored inline.

- Align by position; first divergence = first index where CONTENT_ID differs, or where one run ends early.
  Meta (config, latency) is excluded from identity by design (Phase 2 finding).
- Field-level diff (payload/actor) for the divergent pair.
- DOWNSTREAM_CHANGED_EVENTS: events reachable from the divergent event through DECLARED deps only.
  Events that differ but have no declared path are reported separately as `changed_without_declared_dependency`
  (no causal claim from chronology).
- AFFECTED_CLAIMS: claim events in the declared downstream set, plus claims present in only one run.
- Failures and abstentions from both runs are always listed.
- Identical runs => `DIVERGENCE=NULL`. Never manufactured.
- Attribution limit: with one run per side, the declared variable is the only controlled difference; provider
  nondeterminism is NOT_COMPUTED. Explanation is deterministic templating from facts, no LLM.
