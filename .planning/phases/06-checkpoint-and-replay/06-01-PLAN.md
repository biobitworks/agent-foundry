# Phase 6 Plan 01: Checkpoint and replay

Requirements: REP-01, REP-02. Plan authored inline.

- Checkpoint descriptor derived from a recorded run at a given seq (no mutation of recorded runs; captures are hash-locked).
  Fields: source run, at_seq, prefix content_ids + digest, config, next step. `hydradg_compatible` = UNKNOWN (HydraDG schema not inspected).
- True resume: copy the prefix events into a new run (new run_id, same CONTENT_IDs), then execute the remaining steps
  using the RECORDED evidence text (not the corpus). Only resume point supported: immediately after an `evidence` event.
- Modes: `verify` (same config): replay is compared with the original; `replayable=true` ONLY if DIVERGENCE=NULL.
  `branch` (config override, e.g. another provider): a variant from the same checkpoint; never sets replayable.
- A replay that diverges is reported as REPLAY_DIVERGED, not hidden. n=1 replay per request; nondeterminism NOT_COMPUTED.
